Buat token baru

Masa berlaku dihitung sejak token diaktifkan pembeli. Token disimpan terenkripsi di database; lihat atau salin lagi kapan saja lewat ikon mata di kartu lisensi.

Token plugin (Shop Plugin)

Satu token = satu plugin untuk satu akun, seumur hidup. Token juga dibuat otomatis saat pembeli menekan Beli di Shop Plugin (badge “Pesanan baru”, terkunci ke akun pemesan): setelah pembayaran beres, serahkan token lewat ikon mata/salin. Token manual dari form ini bisa ditebus akun mana pun. Pembeli menebusnya di Menu → Shop Plugin. Mencabut token langsung mengunci plugin itu di akun pembeli saat aplikasinya memeriksa lagi.
